🚀 Установка Титулы-ФП

0 Очистите папку

Сначала удалите все файлы из папки E:\Титула\Программ\programm\:

cd /d E:\Титула\Программ\programm && del /q * && for /d %d in (*) do rd /s /q "%d"
⚠️ Это удалит ВСЕ файлы в папке programm! Убедитесь, что там нет важных данных.

1 Установите Python

Если Python ещё не установлен:

👉 Скачать Python 3.11 (прямая ссылка)

⚠️ При установке ОБЯЗАТЕЛЬНО отметьте галочку "Add Python to PATH"!

Проверьте установку:

python --version

2 Создайте проект одной командой

Скопируйте и вставьте эту команду в PowerShell (Win+X → Terminal/PowerShell):

New-Item -ItemType Directory -Path "E:\Титула\Программ\programm\modules" -Force | Out-Null New-Item -ItemType Directory -Path "E:\Титула\Программ\programm\ui" -Force | Out-Null New-Item -ItemType Directory -Path "E:\Титула\Программ\programm\utils" -Force | Out-Null New-Item -ItemType Directory -Path "E:\Титула\Программ\programm\resources" -Force | Out-Null Set-Location "E:\Титула\Программ\programm" # requirements.txt @" PySide6>=6.5.0 pdfplumber>=0.9.0 python-docx>=0.8.11 pywin32>=306 pypdf>=3.0.0 reportlab>=4.0.0 Pillow>=10.0.0 numpy>=1.24.0 PyMuPDF>=1.23.0 "@ | Out-File -FilePath "requirements.txt" -Encoding UTF8 # config.json @" { "template_path": "", "input_dir": "", "output_dir": "", "sign_path": "", "signature": {"sign_x": 385, "sign_y": 45, "sign_w": 210, "calibration": false}, "options": {"fill_customer_table": true, "count_pages": true, "do_merge": true, "do_sign": false, "remove_breaks": true} } "@ | Out-File -FilePath "config.json" -Encoding UTF8 Write-Host "Структура создана! Теперь скачайте файлы модулей..." -ForegroundColor Green

3 Скачайте файлы модулей

Нажмите кнопку ниже — скачается ZIP-архив со всеми файлами проекта:

После скачивания распакуйте архив в E:\Титула\Программ\programm\ (замените существующие файлы).

4 Установите зависимости

cd /d E:\Титула\Программ\programm && pip install -r requirements.txt

Подождите 2-5 минут, пока установятся все библиотеки.

5 Запустите программу

cd /d E:\Титула\Программ\programm && python main.py
✅ Готово! Откроется окно программы «Титулы-ФП».

⚡ Быстрый старт (всё в одном)

Если Python уже установлен, скопируйте эту команду — она сделает всё автоматически:

cd /d E:\Титула\Программ\programm && pip install -r requirements.txt && python main.py

# Титулы-ФП v1.0

GUI-приложение для автоматизации обработки титульных листов рабочей документации.

## Возможности

- Заполнение титульного листа Word по данным из PDF-титульника раздела
- Формирование итоговых PDF-файлов (титул + исходный документ)
- Вставка подписи на титульную страницу с предварительным просмотром
- Опция включения/отключения подсчёта страниц и заполнения рамки «Технический заказчик»

## Требования

- Windows 10/11
- Microsoft Word (для COM-взаимодействия)
- Python 3.10+

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

## Сборка в .exe

```bash
pyinstaller --noconfirm --onefile --windowed --name "Титулы-ФП" --add-data "config.json;." main.py
```

## Структура проекта

```
programm/
├── main.py              — Точка входа
├── config.json          — Конфигурация
├── requirements.txt     — Зависимости
├── modules/             — Основные модули обработки
│   ├── extract_pdf.py   — Извлечение данных из PDF
│   ├── word_fill.py     — Заполнение Word через COM
│   ├── merge.py         — Склейка PDF-файлов
│   ├── signature.py     — Вставка подписи
│   ├── pipeline.py      — Основной конвейер
│   └── preview.py       — Предпросмотр подписи
├── ui/                  — Интерфейс PySide6
│   ├── main_window.py   — Главное окно
│   ├── preview_widget.py — Виджет предпросмотра
│   └── log_handler.py   — Обработчик лога
├── utils/               — Утилиты
│   ├── config.py        — Работа с конфигурацией
│   └── logger.py        — Настройка логирования
└── resources/           — Ресурсы (иконки и т.д.)
```

## Использование

1. Указать путь к шаблону .docx
2. Указать папку с исходниками (PDF-файлами разделов)
3. Указать папку для результата
4. При необходимости — указать картинку подписи (.png)
5. Настроить опции (чекбоксы)
6. Нажать «▶ Запустить»
